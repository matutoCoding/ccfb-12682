# Fountain Studio · 喷泉编排预演系统

浏览器里的音乐喷泉编排与 3D 预演工具。面向广场 / 景区音乐喷泉工程的方案设计阶段，
在通水调试前就能把「配上音乐跑起来什么样」演示给客户，并输出设备清单和可直接打开的预演文件。

- **纯前端、零后端**：TypeScript + React 18 + WebGL2（手写渲染器，不依赖 Three.js）
- **全本地处理**：工程、音频都存在浏览器 IndexedDB，不上传任何服务器
- **单文件分享**：导出的 `.html` 双击即播，客户无需安装任何软件、无需联网

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建
```

建议使用 Chrome / Edge 最新版（需要 WebGL2 与 Web Audio API）。

## 关键设计

### 音画严格同步（最重要）

所有视觉时间只从一个来源取值：`Transport.currentTime()`，内部是 Web Audio 的
`AudioContext.currentTime` 硬件时钟。rAF 渲染循环每帧读这个时间再求水型状态，
水柱永远追随音频，不会出现「水柱跳了音乐还没到」。循环段用 `BufferSource.loop`
的 `loopStart/loopEnd` 做采样级循环，不靠 JS 定时重启。无音频工程退化为性能时钟。
实测 20 秒连续播放平均 59.8 FPS、P99 帧间隔 17.2ms，漂移恒定不累积。

### 长播放不掉帧

- 水柱顶点缓冲一次性预分配（`DYNAMIC_DRAW`），每帧只 `bufferSubData` 上传，零 GC
- 喷头底座 / 泵 / 灯走实例化绘制（`drawElementsInstanced`）
- 水型状态对象 `evaluateFrame` 复用传入缓冲，不在帧循环里分配对象

### 编辑器与分享文件同源

`src/player/player.raw.js` 是零依赖原生 JS 模块，同时被编辑器 3D 页和导出的单文件
HTML 使用（分享导出时以 `?raw` 整体内联），保证客户看到的画面与编排端逐帧一致。

### 水力学模型（`src/core/physics.ts`）

- 喷口初速 `v = Cd·√(2P/ρ)`，孔流系数 Cd=0.62
- 喷高 `H = η·P·10`（η=0.85 经验效率）
- 流量 `Q = Cd·A·√(2P/ρ)`，泵功率按水功率 ×1.25 安全系数校核
- 水柱为重力抛物线，风偏按经验水平加速度叠加；摇摆喷头按正弦周期改变倾角

### 自动校验

- **DMX 冲突**：通道区间两两求交，冲突通道在设备表红字标出
- **水柱干涉**：平面投影线段最近距离 < 0.6m 判定交叉，水幕按幕宽扇形判定
- **泵功率**：挂载喷头满开水功率求和 ×1.25，超上限报错、>85% 报警

问题同时在布局图上用红 / 黄圈标出，点击问题列表可定位设备。

## 数据与文件

- IndexedDB 库 `fountain-studio-db`：`projects`（工程）、`blobs`（音频二进制）
- 工程导出文件 `*.fpj.json`：含完整工程 JSON 与音频 base64，可发给同事导入续编
- 分享文件 `*-预演.html`：播放器源码 + 工程数据 + 音频全部内联
- 设备表 CSV：带 UTF-8 BOM，Excel 直接打开不乱码
