# 喷泉编排预演系统

广场/景区音乐喷泉工程的方案编排与 3D 预演工具。纯浏览器运行,TypeScript + WebGL2,所有素材和工程文件都在本地处理,不联网。

## 运行

```bash
npm install
npm run dev        # 开发模式
npm run build      # 构建: 产出单个 dist/index.html(整个系统就这一个文件)
npm run preview    # 预览构建产物
```

构建产物是**单文件 HTML**,双击即可使用,也可以直接发给客户。

## 五个页面

| 页面 | 功能 |
|------|------|
| 项目 | 新建/复制/删除工程,自动保存到浏览器本地;导出 `.fountain.json` 工程文件(含音乐),别人导入接着编 |
| 喷头布局 | 直喷/摇摆/跑泉/水幕四种喷头 + 水泵,平面图上拖放布置;框选、六向对齐、整排复制、回路分组;干涉和功率超限直接在图上标红 |
| 曲目编排 | 导入 mp3 自动解析波形;空格打拍/点击节拍行加节拍;BPM 吸附;水型、灯光分轨,拖拽创建片段,双击改参数 |
| 3D预演 | WebGL2 实时渲染:抛物线水柱、灯光染色、水池倒影、风速吹偏;单喷头试喷;导出分享文件 |
| 设备表 | DMX512 通道映射(可编辑),冲突红字提示;设备清单导出 CSV 给采购 |

## 关键设计

**音画同步**:以 `AudioContext.currentTime` 为唯一时钟,渲染循环每帧从音频引擎取音乐时间,不用 rAF 时间戳推算 —— 水柱动作永远跟着音乐走,不会出现"水跳了音乐还没到"。选段循环用 Web Audio 原生 `loopStart/loopEnd`,采样级精确,声音和画面用同一套循环边界。

**帧率稳定**:水柱粒子全部在顶点着色器里算抛物线(每喷头一次 draw call,粒子参数由 `gl_VertexID` 推出),CPU 每帧只写 uniform,零逐帧分配,长时间播放无 GC 压力。

**分享文件**:系统本身是单文件构建,导出分享 = 当前页面 HTML + 内嵌工程数据(含 base64 音乐),客户收到双击打开就是自动播放的 3D 预演,不用装任何东西。

## 物理模型

- 出水初速度 `v = √(2gH)`,H 为扬程(米)× 调压比例
- 轨迹为标准抛物线 + 风速侧向加速度(经验系数)
- 单只功率 `P = ρgQH/η`(η=0.65),泵功率超限自动报警
- 水柱干涉:多相位采样轨迹点,最小间距 < 0.35m 判定干涉

## 测试

```bash
node scripts/smoke.cjs    # 基础流程: 建工程/放喷头/各页面渲染
node scripts/smoke2.cjs   # 音频/编排/播放同步/分享文件端到端
node scripts/smoke3.cjs   # 编排驱动的喷水与灯光染色截图
```

需要先 `npm run build` 并有一个静态服务(脚本默认连 `localhost:5200`,端口被占时自行调整)。
